# 🛍️ Sales Management Frontend (Angular 19)

Frontend application built with **Angular 19** to interact with the Sales Management API. It provides a user interface for managing sales, viewing sale details, and triggering actions such as creation, modification, and cancellation.

## ⚙️ Technologies

- **Angular 19**, **TypeScript**, **RxJS**
- **Docker & Docker Compose**

## 🚀 Features

- Dashboard to view all sales
- Create, edit, and cancel sales
- View sale details including items, discounts, and total value
- Integration with backend API via HTTP
- Responsive UI built with Angular

## ▶️ Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/wesleyheron/Ambev.DeveloperEvaluation.git
   cd frontend

2. **Start the services**:
  ```bash
  docker-compose up --build

## 🌐 Access the Frontend

Once running, the application will be available at:
http://localhost:4200
